# 手动回归清单

录制、权限、界面这些部分没法用单元测试覆盖，靠这份清单在本机手动验证。

- **每个 PR**：只跑改动涉及的章节。
- **每个阶段结束**：全部跑一遍，和上一次的基线对比。
- **记录方式**：结果写进 PR，每项标 ✅ / ❌ / ⏭️（跳过，注明原因），❌ 要写现象。
- **录制类条目**：录 10 秒左右，用 QuickTime 打开，确认画面、声音、时长都对。

## 0. 安装与权限

- [ ] 首次启动提示屏幕录制授权；授权后重启 app 不再提示
- [ ] 重新编译、安装后，屏幕录制 / 麦克风 / 摄像头授权仍然有效
- [ ] 没有屏幕录制权限时（用另一个 bundle id 的副本测，不动正式版的授权）：
  - 启动后系统提示只出现一次，之后不再反复请求（日志里 `+[SCShareableContent …]` 只在启动时出现一次）
  - 点录制按钮：弹出「需要授权」，空的选择器关掉；点「取消」或「打开系统设置」后应用不退出
  - 在系统设置里打开权限后回到应用再点录制：能直接录，或者提示「重新打开 QuickRecorder」，点「重新打开」后应用自动重启

## 1. 主面板与设置

- [ ] 点 Dock 图标打开主面板：
  - 6 个录制图块，每个都能用，顺序是全屏、区域、应用、窗口、移动设备、系统声音；右端一栏上面是关闭 ⊗、下面是 ⚙，中间一条短横线，大小和图块的图标协调；不显示 Dock 和菜单栏图标时 ⚙ 旁边还有电源形状的退出；没有麦克风
  - 悬停图块：柔和高亮（不贴分隔线，淡入淡出），并显示快捷键；按下时微微缩小
  - 按住空白处能拖动；从图块上拖动不会触发录制；Esc 和右端的 ⊗ 能关闭
- [ ] 回到主面板：从主面板开始的流程，在退出选择器（关闭 / Esc / 取消）、取消倒计时、录制结束后，主面板都会回来；在选择器之间切换时不会闪出来；用快捷键或从菜单栏面板开始的录制，结束后不弹出；开着「录制后打开剪辑器」时，等剪辑器关闭后才回来；从主面板 ⚙ 打开的设置，关闭后主面板回来，从菜单栏面板 ⚙ 或 ⌘, 打开的不弹出；选择器或设置开着时点菜单栏图标，菜单栏面板正常展开，主面板不弹出
- [ ] 设置 → 通用 → 外观 → 面板和胶囊材质：Liquid Glass / 毛玻璃 / 纯黑，主面板和胶囊都跟着变；Liquid Glass 的主面板没有黑边
- [ ] 菜单栏面板（开启「在菜单栏中显示」后点菜单栏图标）：
  - 3 列 2 行小图块，顺序和主面板一致；每个图块都能用，移动设备弹出设备小窗；悬停图块显示快捷键
  - 底部一行：⚙ 打开设置，电源图标退出；没有麦克风
- [ ] 设置窗口：工具栏上有五个标签（通用、录制、输出、快捷键、屏蔽列表），点每个都能切；每页是系统的分组表单，说明文字在 ⓘ 里、点开是弹窗；切页时窗口高度跟着内容变，没有内容被裁掉
- [ ] 设置 → 通用 → 主面板置顶：默认开着；关掉后其他应用的窗口能盖住主面板；点 Dock 图标、按快捷键或点菜单栏，主面板回到最前；面板开着时拨动开关立即生效；重启后保留
- [ ] 设置 → 快捷键：每一项都能录入、清除，重启后保留
- [ ] 设置 → 输出 → 保存位置：显示完整路径（`/Users/…/QuickRecoder`），窗口 560 宽时长的路径按中间缩略、末尾的文件夹名看得见；悬停时路径加下划线、指针变成手形，停一下显示完整路径；点路径在访达里打开这个文件夹；「选择…」换一个目录后，显示和点击打开的都是新目录；把文件夹删掉再点，弹出「找不到这个文件夹」，点「好」关掉就结束，点「选择其他文件夹…」直接打开面板换目录

## 2. 录制模式

- [ ] 整个屏幕
- [ ] 屏幕区域（拖选区域；胶囊的「调整大小」气泡里改宽和高）
- [ ] 区域选择的初始选区：第一次在一台没录过的屏幕上打开（删掉该屏的 `savedArea` 记录），选区是可见区域的 60% 居中，不压菜单栏和 Dock（内建 15″ 上是 1026 × 592）；换到小屏/外接屏也按那块屏的可见区域算；改过缩放或从小屏换到大屏后，记住的选区会被夹回屏幕内
- [ ] 每块屏幕各自的选区：在 A 屏录完，去 B 屏再录一次，回到 A 屏还是 A 上次的选区（两块屏各记一条，互不覆盖）
- [ ] 在「调整大小」里改宽高：选区以原来的中心为基准变大变小，不会跳回屏幕正中
- [ ] 取消（Esc 或胶囊的 ×）时的选区也会记住：摆好一个选区，取消，再打开还是它
- [ ] 区域选择的样式（深色、浅色模式各看一次）：
  - 打开时选区外的磨砂淡入，磨砂较轻，能看出后面窗口和文字的轮廓（深色模式略暗、浅色模式略亮）；在「编辑选区」里改宽高时磨砂不闪；选区边缘一道亮边，四角是直角细线
  - 尺寸显示在选区内顶部居中，离上边 10 pt；选区上边推到屏幕顶、尺寸正对刘海时，它移到刘海下方 6 pt，看得见；选区在刘海两侧时尺寸不动，可以在菜单栏那一条里；沿顶部左右拖过刘海，尺寸在刘海处下移再回来
  - 选区很窄或很矮时尺寸在选区上方；上方放不下或会碰到刘海时在选区下方
  - 外接屏（没有刘海）上选区贴顶时，尺寸就在选区顶部 10 pt 处
  - 光标：四角和四条边上是调整大小，选区里是抓手（按下时握拳），选区外是十字
  - 鼠标靠近哪条边，那条边的中点长出短条；移到角上，那个角伸长一点；整条边任意位置都能拖
  - 移动、调整大小、重新框选时磨砂变淡，松手后恢复
  - 开始录制后，选区外只留四个角，录像里看不到它们（区域和「窗口范围」各录一次）
- [ ] 单个窗口：从窗口列表选，以及直接点选（窗口选择器工具栏的按钮，和区域选择器的「窗口范围」）；点选后在那个窗口底部浮出胶囊，能开始录制，× 和 Esc 取消
- [ ] 选择器里点缩略图：缩略图外出现强调色描边和右上角的勾，再点取消；悬停时有柔和浅底；屏幕卡片是显示器的真实比例；多显示器时打开的是选择器所在屏幕的标签页
- [ ] 屏幕、窗口、应用选择器里按 Esc：关闭选择器，从主面板打开的回到主面板；气泡开着时第一次 Esc 只收起气泡；剪辑窗口按 Esc 不关闭
  - 先切到别的应用（主面板仍在），再点主面板的图块：选择器打开时 QuickRecorder 到前台，不点选择器直接按 Esc 也能关闭
- [ ] 选择器胶囊（屏幕、区域、窗口、应用、点选窗口都一样）：
  - 鼠标、App 声音、麦克风、计时：单击开关；开时是各自的颜色（蓝、橙、绿、红），关时是灰色斜杠；计时器的图标是闹钟
  - 右击（或 Control 单击）麦克风弹出设备列表，选完收起；右击计时弹出「时 分 秒 重置」；右击窗口选择器的刷新弹出「显示无标题窗口 / 不生成缩略图」
  - 计时：没设过时长时单击打开用 10 分钟；关掉后记住时长；改时长不改开关，重置把时长清零并关掉计时；开着计时录制，到时长自动停止
  - 时长输入超出范围的数字（如 75 秒、100 小时、负数）变成 0；没按回车就点外面，输入也会保存
  - 选项：分辨率 Retina / 标准，帧率只到这块屏幕的刷新率（60 Hz 屏幕最高 60），画质高 / 中 / 低，背景色块（只在应用），HDR
  - 背景：壁纸、黑、白、灰、蓝、绿、自定义七格；黄、橙、红不再出现在这一行
  - 选「自定义」：气泡右侧打开颜色窗口，底边和气泡对齐、离气泡 16 pt；悬停色块时上方预览跟着变，点击才生效，「自定义」色块中间变成这个颜色；右下角色轮打开系统调色板，在里面选的颜色同样生效
  - 在颜色窗口和系统调色板里点击时，选项气泡不收起；点系统调色板自己的关闭按钮只关调色板，气泡和颜色窗口都还在；Esc 先关窗口（连同调色板），再按一次收气泡，第三次才离开选择器
  - 点别的背景，颜色窗口自己收起；从窗口的 × 关闭后，气泡还在
  - 颜色窗口开着时，点「选项」气泡里其它空白处（标签、行间、内边距）：颜色窗口收起，气泡还在；点气泡里的按钮（分辨率、画质、HDR 等）不收起窗口
  - 录出来的背景就是这个颜色；设置里没有「自定义背景颜色」；原来存的是黄、橙、红的话，现在显示为「自定义」且颜色不变
  - 气泡一次只开一个，跟随「面板和胶囊材质」；点气泡外面任何地方、切到别的应用、按 Esc 都会收起；点打开它的那个图标只收起
  - 气泡刚打开就点它最靠边的控件（比如「选项」里最右边的「自定义」色块、最左边的标签），气泡不收起；区域选择的「选项」也试一次
  - 胶囊和气泡里没有任何悬停提示
  - 区域和点选窗口的浮动胶囊：Liquid Glass 下没有黑边；打开气泡时胶囊不动；区域里第一次 Esc 收起气泡，第二次才取消选区
- [ ] 应用程序（选多个应用）
- [ ] 背景只作用于应用录制：窗口录制的「选项」里没有「背景」这一行
  - 应用录制（选多个应用也一样）选「壁纸」：应用窗口以外的地方是桌面壁纸，不是黑底；选纯色：窗口以外是那个颜色
  - 屏幕和区域的「选项」里没有「背景」；在应用选择器里选了纯色后，用快捷键或 AppleScript 录整个屏幕，壁纸照常
- [ ] 录制系统声音（主面板和菜单栏面板的图块）：屏幕底部浮出胶囊「关闭 | 麦克风 计时 | 录制」，没有鼠标、App 声音和选项；× 和 Esc 关闭并回到主面板；右击麦克风选设备，右击计时设时长，两个气泡都完整显示、不被截断，胶囊本身不移动；开着计时录到时长自动停止；快捷键和 AppleScript 照旧直接开始录
- [ ] 仅系统音频（AAC 和 ALAC 各一次）
- [ ] iPhone / iPad（有设备时）
- [ ] AppleScript：`record window titled "…"`、`record system audio with microphone` 能开始录制；锁屏时也不会没反应（能录就录，没有显示器时弹出提示）

## 4. 录制控制

- [ ] 胶囊：开始录制时从刘海弹出、停止时收回；停止、暂停 / 继续、摄像头按钮都能用
- [ ] 胶囊不出现在录像里（「排除 QuickRecorder 自身」开和关各录一次，查看刘海下方）
- [ ] 「排除 QuickRecorder 自身」开着时，录制中打开的摄像头弹窗、「● 计时」菜单不出现在录像里（全屏、区域、应用；和「录制菜单栏画面」无关）；摄像头浮窗、鼠标高亮照常录进去
- [ ] 胶囊：鼠标移开 1 秒后淡到设置的不透明度，移入立即恢复；暂停和倒计时中不变淡
- [ ] 胶囊三种材质（设置 → 通用 → 外观 → 面板和胶囊材质）切换后生效
- [ ] 菜单栏「● 计时」：原生菜单里暂停、继续、停止都能用，菜单项上显示设置的快捷键
- [ ] 设置 → 录制控制：两个开关不能同时关闭
- [ ] 快捷键：开始（屏幕 / 区域 / 窗口 / 系统音频）、暂停 / 继续、停止
- [ ] 暂停、继续多次后停止：文件可播放，时长等于实际录制时长
- [ ] 录制前倒计时（胶囊开启时显示在胶囊里，可取消）
- [ ] 录制被意外中断时，文件照常保存可播放，并弹出「录制已停止」通知写明原因；正常停止时不弹：
  - 被录窗口关闭：约 5 秒后停止（窗口关掉后那几秒只有声音）
  - 被录应用全部退出：立即停止
  - 在系统菜单栏的屏幕录制指示里停止
  - 合盖 / 睡眠：立即停止，通知等解锁后才弹出
  - 锁屏不会中断录制
- [ ] 录制中退出 QuickRecorder（⌘Q、菜单里的退出）：先停止录制，等麦克风混进主音轨后才退出；留下的是最终文件，没有 `_Unmixed`。纯音频（系统声音 + 麦克风）也一样，生成 `AudioRecording_….m4a`
