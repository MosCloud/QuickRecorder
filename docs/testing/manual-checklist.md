# 手动回归清单

录制、权限、界面这些部分没法用单元测试覆盖，靠这份清单在本机手动验证。

- **每个 PR**：只跑改动涉及的章节。
- **每个阶段结束**：全部跑一遍，和上一次的基线对比。
- **记录方式**：结果写进 PR，每项标 ✅ / ❌ / ⏭️（跳过，注明原因），❌ 要写现象。
- **录制类条目**：录 10 秒左右，用 QuickTime 打开，确认画面、声音、时长都对。

## 0. 安装与权限

- [ ] 首次启动提示屏幕录制授权；授权后重启 app 不再提示
- [ ] 重新编译、安装后，屏幕录制 / 麦克风 / 摄像头授权仍然有效

## 1. 主面板与设置

- [ ] 点 Dock 图标（或菜单栏图标）打开主面板
- [ ] 能打开设置窗口，各分页都能切换
- [ ] 设置 → 快捷键：每一项都能录入、清除，重启后保留

## 2. 录制模式

- [ ] 整个屏幕
- [ ] 屏幕区域（拖选区域、调整大小）
- [ ] 单个窗口
- [ ] 应用程序（选多个应用）
- [ ] 仅系统音频（AAC 和 MP3 各一次）
- [ ] iPhone / iPad（有设备时）

## 3. 音频

- [ ] 只录系统声音
- [ ] 只录麦克风（默认设备）
- [ ] 系统声音 + 麦克风，「录制麦克风到主音轨」开：一条混合音轨
- [ ] 系统声音 + 麦克风，「录制麦克风到主音轨」关：两条独立音轨
- [ ] 开启回声消除录制，停止后不闪退

## 4. 录制控制

- [ ] 菜单栏：暂停、继续、停止
- [ ] 快捷键：开始（屏幕 / 区域 / 窗口 / 系统音频）、暂停 / 继续、停止
- [ ] 暂停、继续多次后停止：文件可播放，时长等于实际录制时长
- [ ] 录制前倒计时

## 5. 录制后

- [ ] 浮动预览出现，可打开、拖拽、删除
- [ ] 「录制后打开剪辑器」开启时，剪辑器能打开并导出
- [ ] 「保存当前帧」快捷键生成图片

## 6. 叠加效果

- [ ] 高亮鼠标
- [ ] 屏幕放大镜（快捷键开关）
- [ ] 摄像头悬浮窗；macOS 的演讲者叠加（Presenter Overlay）
- [ ] HDR 录制
- [ ] 带透明通道录制（HEVC with Alpha）

## 7. 长时间录制（只在阶段结束时跑）

- [ ] 连续录制 30 分钟不中断，文件完整
