# 手动回归清单

录制、权限、界面这些部分没法用单元测试覆盖，靠这份清单在本机手动验证。

- **每个 PR**：只跑改动涉及的章节。
- **每个阶段结束**：全部跑一遍，和上一次的基线对比。
- **记录方式**：结果写进 PR，每项标 ✅ / ❌ / ⏭️（跳过，注明原因），❌ 要写现象。
- **录制类条目**：录 10 秒左右，用 QuickTime 打开，确认画面、声音、时长都对。

## 0. 安装与权限

- [ ] 首次启动提示屏幕录制授权；授权后重启 app 不再提示
- [ ] 重新编译、安装后，屏幕录制 / 麦克风 / 摄像头授权仍然有效

## 1. 主面板与设置

- [ ] 点 Dock 图标打开主面板：
  - 6 个录制图块，每个都能用；右端是麦克风开关、设备名（点开可换设备）和 ⚙；不显示 Dock 和菜单栏图标时还有 ⊗ 退出
  - 悬停图块：柔和高亮（不贴分隔线，淡入淡出），并显示快捷键；按下时微微缩小
  - 按住空白处能拖动；从图块上拖动不会触发录制；Esc 和左上角 x 能关闭
- [ ] 回到主面板：从主面板开始的流程，在退出选择器（关闭 / Esc / 取消）、取消倒计时、录制结束后，主面板都会回来；在选择器之间切换时不会闪出来；用快捷键或从菜单栏面板开始的录制，结束后不弹出；开着「录制后打开剪辑器」时，等剪辑器关闭后才回来；从主面板 ⚙ 打开的设置，关闭后主面板回来，从菜单栏面板 ⚙ 或 ⌘, 打开的不弹出；选择器或设置开着时点菜单栏图标，菜单栏面板正常展开，主面板不弹出
- [ ] 设置 → 通用 → 外观 → 面板和胶囊材质：Liquid Glass / 毛玻璃 / 纯黑，主面板和胶囊都跟着变；Liquid Glass 的主面板没有黑边
- [ ] 菜单栏面板（开启「在菜单栏中显示」后点菜单栏图标）：
  - 3 列 2 行小图块，顺序和主面板一致；每个图块都能用，移动设备弹出设备小窗；悬停图块显示快捷键
  - 底部麦克风开关：开为绿色麦克风，关为灰色带斜杠，设备选择跟着变灰；开关状态和主面板同步
  - ⚙ 打开设置，⊗ 退出
- [ ] 能打开设置窗口，各分页都能切换
- [ ] 设置 → 快捷键：每一项都能录入、清除，重启后保留

## 3. 音频

- [ ] 只录系统声音
- [ ] 只录麦克风（默认设备）
- [ ] 系统声音 + 麦克风，「录制麦克风到主音轨」开：一条混合音轨
  - 录制中保存文件夹里是 `…_Unmixed.mp4`，停止后变成正式文件名，不留 `_Unmixed` 或 `.mp4.mp4.mp4`
  - 连续录、停 5～10 次不闪退，停止没有明显卡顿
- [ ] 系统声音 + 麦克风，「录制麦克风到主音轨」关：两条独立音轨
- [ ] 指定麦克风设备（非默认）录制：有麦克风声音
- [ ] 默认麦克风是蓝牙耳机：从耳机处于听歌状态时开始录，麦克风有声音；录到一半断开或连上耳机，麦克风音轨不中断（关掉「录制麦克风到主音轨」，录完检查独立的麦克风音轨）
- [ ] 仅系统音频 + 麦克风：只生成一个音频文件（没有 `.qma`），系统声音和麦克风都在里面

## 4. 录制控制

- [ ] 胶囊：开始录制时从刘海弹出、停止时收回；停止、暂停 / 继续、摄像头按钮都能用
- [ ] 胶囊不出现在录像里（「排除 QuickRecorder 自身」开和关各录一次，查看刘海下方）
- [ ] 胶囊：鼠标移开 1 秒后淡到设置的不透明度，移入立即恢复；暂停和倒计时中不变淡
- [ ] 胶囊三种材质（设置 → 通用 → 外观 → 面板和胶囊材质）切换后生效
- [ ] 菜单栏「● 计时」：原生菜单里暂停、继续、停止都能用，菜单项上显示设置的快捷键
- [ ] 设置 → 录制控制：两个开关不能同时关闭
- [ ] 快捷键：开始（屏幕 / 区域 / 窗口 / 系统音频）、暂停 / 继续、停止
- [ ] 暂停、继续多次后停止：文件可播放，时长等于实际录制时长
- [ ] 录制前倒计时（胶囊开启时显示在胶囊里，可取消）
- [ ] 录制被意外中断时，文件照常保存可播放，并弹出「录制已停止」通知写明原因；正常停止时不弹：
  - 被录窗口关闭：约 5 秒后停止（窗口关掉后那几秒只有声音）
  - 被录应用全部退出：立即停止
  - 在系统菜单栏的屏幕录制指示里停止
  - 合盖 / 睡眠：立即停止，通知等解锁后才弹出
  - 锁屏不会中断录制

## 5. 录制后

- [ ] 浮动预览：从右侧滑入的横条卡片，材质跟随「面板和胶囊材质」
  - 视频显示第一帧，音频显示真实波形；有时长标签，文件名在垃圾桶的位置截断，下面是「时长 · 大小」
  - 打开、在访达中显示、剪辑、移到废纸篓四个按钮都能用（视频和音频一样）；悬停时左上角出现 ×
  - 把缩略图拖进访达或聊天窗口，得到这个文件；双击缩略图打开
  - 双指向右轻扫会关掉；6 秒内没有操作会滑出去，鼠标停在上面时不会
  - 右键：拷贝、共享…、制作 GIF（仅视频）、关闭
- [ ] 麦克风 + 系统声音 +「录制麦克风到主音轨」开时，混音完成后也出现浮动预览，缩略图是这次录制的画面
- [ ] 「录制后打开剪辑器」开启时，剪辑器能打开并导出
- [ ] 仅系统音频的录制（.m4a）也能在剪辑器里修剪并保存，生成「AudioRecording_…_Trimmed.m4a」
- [ ] 「保存当前帧」快捷键生成图片
- [ ] 通知以横幅弹出（QuickRecorder 在前台时也一样），而不是直接收进通知中心；带麦克风的录制结束时不再弹「仍在处理」
- [ ] 文件名全英文、不带空格：视频 `ScreenRecording_2026-10-27_10.21.58.mp4`，音频 `AudioRecording_….m4a`，当前帧 `Screenshot_….png`，剪辑后 `…_Trimmed.mp4`（重名时 `…_Trimmed-2`）
